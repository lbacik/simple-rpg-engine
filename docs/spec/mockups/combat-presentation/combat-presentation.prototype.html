Combat presentation: abstract exchange vs grid board

Prototype for the question “Does a simple tactical grid board fit the prototype, or does Combat stay abstract?” The same agreed Combat rules (2d6 + Might ≥ 7 + Agility, defend, Consumables, escape) are played in three presentations. Play the same fight (same Template, Enemy and dice seed) in each variant with ←/→ and compare: how many clicks a fight takes, whether any choice feels meaningful, and how much extra spec each variant drags in.
