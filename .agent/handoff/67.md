## Summary

Implemented the Journal modal (issue #67) using TDD. New `JournalModalLink`
client component (`src/app/play/[playthroughId]/journal/journal-modal.tsx`)
wraps a plain journal link: without JS it navigates to the full Journal page;
with JS it opens the modal (newest-first `JournalEntries` with infinite
scroll and position indicator inside the modal body, "Open in new tab" with
`target=_blank`, Close/Escape/backdrop close, focus trap + restore,
background scroll lock). Wired into all three screens in
`src/app/play/[playthroughId]/page.tsx` (game screen, Ending screen with
`button secondary` styling, incompatible-with-Scenario screen) via a new
`newestJournalBatch` helper in `src/app/lib/journal.ts`; modal CSS in
`globals.css`; `docs/spec/ui.md` Journal section rewritten for modal +
standalone page. Also fixed `scripts/start-standalone.mjs` to sync
`.next/static` into the standalone dir on startup (mirrors the Dockerfile
COPY) — without this, `npm run start` serves no client JS and every e2e
click degrades to a full navigation. New unit tests
(`tests/journal-modal.test.tsx`, 5 tests) and new Playwright spec
(`tests/e2e/journal-modal.spec.ts`) both pass; full vitest suite (406
tests), `lint`, `typecheck`, `validate scenarios/whispering-woods` and
`build` all pass.
